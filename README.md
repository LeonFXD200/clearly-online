# Good Measure — Personal direction

An original website for a Sevenoaks/Kent web design business, taking visual inspiration from Rudo's dark green palette, friendly typography and personal call to action. All layout, copy, graphics and code are original. The portrait was supplied by the owner for use on this website. No reference-site assets or code are included.

## Run locally

Open `index.html` or serve this directory with `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publish

GitHub Pages serves the root of the `main` branch. There is no build step. Push changes to `main` to publish.
